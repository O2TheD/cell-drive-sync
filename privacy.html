Privacy policy: Cell Drive Sync

Last updated: 30 October 2026

Cell Drive Sync is a personal tool operated by Ohad Ellert for his own use. It is not offered to anyone else.

What it accesses

It requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. With this scope Google lets the tool access only files and folders the tool itself created. It cannot see any other content in the Drive, nor email, contacts or other Google data.

How data is used

The tool uploads files from its owner's own server into the owner's own Drive folder, and reads and updates those same files. The OAuth credentials are stored only on that server, readable only by the account that runs the tool.

Sharing

No data is sold, shared with third parties, used for advertising, or used to train AI models. Google user data is used solely to provide the sync described above.

Removal

Access can be revoked at any time at myaccount.google.com/permissions. Files the tool created stay in the owner's Drive until the owner deletes them.
