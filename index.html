Cell Drive Sync

Cell Drive Sync is a private, single-user tool run by Ohad Ellert. It copies files from his own server (printable coloring-page packs for the Little Pause shop, server logs and backups) into one folder, Project Cell, in his own Google Drive.

  • It is used only with its owner's own Google account and is not offered to the public.
  • It uses Google's narrowest Drive permission, drive.file, so it can only see and change files it created itself. It cannot read anything else in the Drive.
